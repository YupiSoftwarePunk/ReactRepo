Что такое реактивность и иммутабельность в React?

1.  Реактивность: React следит за состоянием (useState). Когда вы вызываете функцию обновления стейта (например, setItems),
    React смотрит на ссылку на новые данные. Если ссылка изменилась, React понимает, что данные обновились, и запускает
    перерисовку компонента (re-render).
2.  Мутабельность (неправильно): Это прямое изменение старых данных в памяти (например, arr.push(newItem) или obj.name =
    'Ivan'). Ссылка на объект/массив при этом не меняется, поэтому React думает, что ничего не изменилось, и интерфейс не
    обновляется.
3.  Иммутабельность (правильно): Это создание копии данных (с помощью спред-оператора ..., методов map, filter), внесение
    изменений в копию и запись её в стейт. React видит новую ссылку и обновляет экран.
